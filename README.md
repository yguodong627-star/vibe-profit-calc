# 利润定价计算器 · Profit & Price Calculator

> 小卖家工具箱 01。纯前端，打开网页即用，无需注册、无 API key，数据只存在你自己的浏览器里。

**在线使用**：https://yguodong627-star.github.io/vibe-profit-calc/

## 谁会用

在 Etsy、亚马逊、Shopify、eBay、淘宝、小红书上卖货的个人和小团队卖家，尤其是：

- 第一次给新品定价，不确定扣完平台费、运费、广告、退货后还剩多少
- 同一件商品想比较“放哪个平台更赚钱”
- 手上有几十个 SKU，想批量看哪些其实在亏钱（Pro）

## 解决什么问题

- 平台费用拆成佣金、支付手续费、刊登费、广告、退货损失，一眼看到钱花在哪
- 输出每件利润、利润率、**盈亏平衡价**，并按**目标利润率反推建议售价**
- 退货按“期望值”计入：退货率、退回运费、退回后可再售比例、平台费是否退还都可调
- 成本币种与售价币种可以不同，汇率由你手动填写并保存（不内置汇率，避免过期数据误导）
- 保存情景到本地，多个情景并排对比

## 隐私

没有后端，没有统计脚本，没有网络请求。所有输入、情景、模板、汇率、授权码都存在浏览器 localStorage，清除浏览器数据会丢失。

## 本地运行 / 测试

直接打开 `index.html`，或 `python3 -m http.server`。测试在 `tests/`（需要 puppeteer-core 和本机 Chrome）：

```
python3 -m http.server 8765 &
NODE_PATH=/path/to/node_modules node tests/selftest.js
```

## 已知限制

- 不支持分档费率（如亚马逊服装 5%/10%/17%、eBay 7500 美元以上 2.35%）
- 不计税（销售税、VAT、增值税）、不计月租/保证金等固定成本分摊
- 刊登费按“每件摊一次”处理，没有做库存件数摊销
- Pro 授权为占位实现
